# 📄 OCR Text Extractor

This is a simple Streamlit app that extracts text from images, PDF files, and Word documents using OCR (Optical Character Recognition).

---

## 📁 Supported File Types

- 📷 Images: JPG, JPEG, PNG  
- 📄 PDF documents  
- 📝 Word documents (.docx)

---

## ⚙️ How to Run
```

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Install Tesseract OCR:

- Windows: https://github.com/tesseract-ocr/tesseract  
- Linux:
```bash
sudo apt install tesseract-ocr
```

3. Run the app:

```bash
streamlit run app.py
```

---

## 📦 Requirements

- streamlit  
- pillow  
- pytesseract  
- pymupdf  
- python-docx  
- opencv-python
